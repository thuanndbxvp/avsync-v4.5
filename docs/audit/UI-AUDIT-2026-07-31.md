```python
fx_map = {"none": "none", "vừa": "vua", "nhẹ": "nhe", "mạnh": "nang"}
cfg = {
    "effect": fx_map.get(self.cmb_fx.currentText(), "rain"),  # ← bug: không map effect thật

```

- Thiếu hẳn dropdown chọn effect (rain/snow/fog/bokeh).
